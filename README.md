# Складской учёт (WarehouseJSON)

Учебный программный модуль для учёта товаров на складе небольшого магазина.

## Назначение
Модуль-отправитель формирует партии товаров и передаёт их в JSON-формате,
модуль-получатель проверяет данные, обновляет остатки и строит отчёты.

## Целевая аудитория
Кладовщики и администраторы небольших магазинов.

## Основные функции
1. Приём партии товаров (приход).
2. Списание товаров (расход) с проверкой остатка.
3. Проверка корректности входящих данных (валидация).
4. Поиск товара по артикулу.
5. Отчёт об остатках и о товарах с низким запасом.
6. Логирование и отладочный вывод.

## Структура
- `src/` — исходный код (module_a, module_b, main, exceptions, debug_helper)
- `docs/` — документация и результаты тестирования
- `config/` — настройки (config.json)
- `scripts/` — скрипты запуска
- `lib/` — вспомогательные библиотеки
- `test/` — unit-тесты PyTest

## Запуск
```
python src/main.py
python -m pytest test/ -v
```
